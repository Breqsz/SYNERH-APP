## 🎯 Disciplina Foco: Mobile Development and IOT

Este projeto atende especificamente aos requisitos da disciplina **Mobile Development and IOT**.

### Requisitos Atendidos:

✅ **React Native com Expo**
- Framework escolhido para desenvolvimento mobile
- Expo SDK 51 (versão mais recente estável)

✅ **Navegação Híbrida**
- Stack Navigator: Fluxo de autenticação (Splash → Login → Register)
- Bottom Tabs Navigator: App principal (Home, Quests, AI)

✅ **Firebase Authentication**
- Login com email e senha
- Registro de novos usuários
- Gerenciamento de sessão

✅ **Firebase Realtime Database**
- Persistência de dados do usuário
- Armazenamento de quests aceitas
- Atualização em tempo real

✅ **Integração com API de IA**
- OpenAI GPT-3.5-turbo
- Recomendações personalizadas
- Fallback com dados mockados

✅ **Componentes Obrigatórios (10/10)**
- View, ScrollView, TextInput, Text
- Button, Image, StyleSheet
- TouchableOpacity, Alert, Picker

✅ **Dados Mockados**
- Simulação de backend SOA
- 8 quests de diferentes categorias
- 8 cursos do Learning Pool
- Estatísticas e notificações

## 📝 Observações de Desenvolvimento

### Escolhas Técnicas:

1. **Expo vs React Native CLI**
   - Escolhido: Expo (facilidade de setup e desenvolvimento)
   - Benefícios: Zero config, hot reload, fácil deploy

2. **Firebase vs Backend Custom**
   - Escolhido: Firebase (MVP rápido)
   - Benefícios: Autenticação pronta, banco em tempo real

3. **OpenAI vs Outras IAs**
   - Escolhido: OpenAI GPT-3.5-turbo
   - Benefícios: Melhor qualidade, API simples

4. **Dados Mockados**
   - Implementado para simular integração futura com SOA backend
   - Permite teste completo sem dependências externas
